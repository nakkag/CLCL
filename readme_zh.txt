CLCL Ver 2.2.1
--

* 简介
CLCL 是一款保存剪贴板历史记录的软件。

* 功能特点
- 支持多种剪贴板格式。
- 可以将常用文本以层级结构注册为模板。
- 可以自由定制通过热键显示的菜单。
- 在菜单中选择的历史记录或模板项目，会自动粘贴到您正在使用的编辑器中。
- 图片在菜单中以缩略图的形式显示。
- 菜单中会显示工具提示。
- 可以设置要保存到历史记录中的格式，以及要写入文件的格式。
- 可以设置要保存历史记录的窗口，以及要忽略的窗口。
- 可以为每个窗口分别设置粘贴键。
- 退出时自动保存历史记录，下次启动时恢复。
- 历史记录的项目数量没有限制。
- 可以在类似资源管理器的查看器中显示和编辑历史记录与模板。
- 可以通过添加插件来扩展功能。
- 支持 Unicode

* 安装
CLCL 可在 Windows 7 及更高版本上运行。

运行下载的文件即可安装 CLCL。
卸载 CLCL 请使用控制面板。
卸载之前请先退出 CLCL。

数据保存在以下目录中（Windows 10 的情况）：
  C:\Users\(用户名)\AppData\Local\CLCL

如果希望将数据保存在与 CLCL.exe 相同的位置，请按如下方式设置
clcl_app.ini，然后启动 CLCL。

[GENERAL]
portable=1

* 启动
CLCL 启动后，系统托盘（任务栏上显示时钟的区域）中会出现一个回形针图标。
点击该托盘图标即可显示菜单。
默认情况下，菜单中的历史记录按升序显示。
菜单可以在选项中进行定制。

右键点击托盘图标即可显示查看器。
查看器的左侧是显示历史记录与模板的树状结构。
查看器的右侧用于显示和编辑历史记录或模板项目的内容。所做的编辑会在焦点
移开时应用到该项目。部分格式无法编辑。剪贴板的当前内容也无法编辑。

树状结构顶部的“剪贴板”是剪贴板的当前内容。
树状结构中的“历史”是历史记录的列表。
树状结构中的“模板”是已注册项目（模板文本等）的列表。

    +--[+] 剪贴板           - 当前剪贴板的内容
    |   +--- TEXT           - 剪贴板中的格式
    |   +--- LOCALE
    |   +--- OEM TEXT
    |
    +--[+] 历史             - 剪贴板历史记录
    |   +--- (BITMAP)       - 历史记录项目
    |   |   +--- BITMAP     - 历史记录项目中的格式
    |   |   +--- DIB
    |   |
    |   +--- 你好...
    |   |   +--- TEXT
    |   |
    |   +--- 早上好...
    |   +--- (BITMAP)
    |
    +--[+] 模板             - 已注册的项目
        |
        +--[+] 目录         - 目录
        |   +--- 地址...
        |   +--- (BITMAP)
        |
        +--- http://www...  - 模板项目
            +--- TEXT       - 模板项目中的格式

* 剪贴板
- 什么是剪贴板？
	剪贴板是用于在不同应用程序之间交换信息的区域。
	例如，在记事本中复制的文本可以粘贴到 Word 中，这正是因为使用了
	名为剪贴板的区域。

- 剪贴板格式
	剪贴板可以同时保存多种格式。
	例如，在记事本中复制文本时，剪贴板中会放入以下四种格式
	（Windows 10 的情况）：
		- UNICODE TEXT
		- LOCALE
		- TEXT
		- OEM TEXT
	在 Excel 或 Access 中复制时，会有更多的格式被发送到剪贴板。

	默认情况下，CLCL 会将以下格式保存到历史记录中：
		- UNICODE TEXT		- 文本
		- BITMAP		- 图片
		- DROP FILE LIST	- 文件
	其他格式也可以通过选项中的“筛选”保存到历史记录中。

* 历史
这是复制到剪贴板中的数据的历史记录。
新复制的数据会添加到历史记录的顶部。

一条历史记录项目中保存有多种剪贴板格式。在选项中的“格式”里注册的格式
中，优先级最高的剪贴板格式会显示在菜单和查看器中。

历史记录会按照选项中的“历史”所设置的数量保存项目。
只有在选项中的“筛选”里设置为“添加到历史记录”的剪贴板格式才会被添加
到历史记录中。

* 模板
模板文本等常用数据可以注册到模板中。
可以添加目录来构建层级结构，也可以为项目命名。

要添加模板项目，请打开查看器，在历史记录中选择项目，然后从菜单中选择
“添加到模板”。
如果在树状结构中选择要添加到的目录，然后从菜单中选择“新项目”，就可以
创建空白项目，或者从文件读取内容来创建项目。

要添加目录，请打开查看器，在模板中要添加的位置打开右键菜单，然后选择
“创建目录”。

要重命名目录或项目，请打开查看器，选择要修改的项目，打开右键菜单，然后
选择“重命名”。
“重置成原始名称”会删除您设置的名称，使项目的内容作为其名称显示。
如果将项目命名为“-”，它在菜单中会显示为分隔线。此时该项目的格式和数据
将被忽略。
如果在名称中加入 &，其后的字符会成为菜单中的快捷键。若要在菜单中显示 &
本身，请写成 &&。

右键点击模板项目打开菜单，选择“热键设置”，即可为该模板项目分配热键。
按下该热键时，模板项目会直接发送到剪贴板而不显示菜单；如果启用了
“自动粘贴”，还会直接粘贴。
已分配的热键可以在查看器的列表中确认。选中模板项目时，状态栏中也会显示
该热键。

模板项目的数量及其剪贴板格式的数量没有限制。

* 发送到剪贴板
将历史记录或模板项目发送到剪贴板有以下几种方法。
- 点击系统托盘图标显示菜单。
  选择历史记录或模板项目后，数据会被发送到剪贴板，并自动粘贴到活动窗口
  中。

- 按下热键（默认为 Alt + C）显示菜单。
  选择历史记录或模板项目后，数据会被发送到剪贴板，并自动粘贴到活动窗口
  中。

- 在查看器中选择项目并打开右键菜单。
  选择“发送到剪贴板”即可将选中的项目发送到剪贴板。

* 菜单
从系统托盘或通过热键显示的菜单中的项目，在选项中的“动作”里设置。
菜单的行为和外观在选项中的“菜单”里设置。

将鼠标移动到菜单中的历史记录或模板项目上时，详细内容会在鼠标位置以工具
提示的形式显示。使用键盘选择项目时，工具提示会显示在该菜单项的下方。

右键点击菜单中的历史记录或模板项目时，会以菜单的形式显示已注册的工具；
选择的工具会应用到该项目，处理结果将被发送到剪贴板。
若要用键盘显示工具菜单，请按住 Ctrl 的同时用回车键选择项目。

历史记录和模板项目按照选项中的“菜单显示格式”显示在菜单中。显示的编号
从 0 开始；若要更改起始值，请在 % 与字符之间写入起始编号。
    示例）
         %0d -> 0,1,2,3...
         %8x -> 8,9,a,b...
         %1n -> 1,2,3...8,9,0,1,2...
         %10B -> K,L,M,N...

* 动作
按下热键时执行的动作，以及点击系统托盘图标时执行的动作，在选项中的
“动作”里设置。

如果在“编辑动作”中将动作指定为“菜单”，请在对话框下方的菜单设置中
设置要显示的菜单项目。

“触发类型”用于设置以何种方式调用指定的动作。
如果指定为“热键”，请设置用于调用的按键。
“Ctrl + Ctrl”、“Shift + Shift”和“Alt + Alt”会在按键连按两次时调用
指定的动作。

当动作为菜单时，可以设置“自动粘贴”。
启用“自动粘贴”后，在菜单中选择项目时，会自动向您正在使用的应用程序
发送粘贴操作。
如果在选择菜单项目时按住 Shift，则数据只会被发送到剪贴板而不会粘贴。

当动作为菜单，且触发类型为“热键”、“Ctrl + Ctrl”、“Shift + Shift”
或“Alt + Alt”时，可以设置“在光标位置显示”。
启用“在光标位置显示”后，菜单会显示在编辑器中光标所在的位置。未设置时，
菜单将显示在鼠标位置。

当动作为菜单且内容为历史记录时，可以设置显示范围。显示范围的指定值为
1 至历史记录中保存的最大项目数量。将起始编号指定为 0 与指定为 1 相同，
将结束编号指定为 0 与指定为历史记录中保存的最大项目数量相同。
如果结束编号小于起始编号，则不显示任何内容。如果结束编号大于历史记录中
保存的最大项目数量，则只显示到该最大数量为止。

* 剪贴板格式
CLCL 可以处理所有剪贴板格式，但未注册的剪贴板格式在查看器中会以二进制
形式显示。

剪贴板格式在选项中的“格式”里注册。在列表中位置越靠上的格式优先级越高，
项目中优先级最高的剪贴板格式会显示在菜单和查看器中。

注册格式时，请设置格式名称、进行处理的 DLL 以及函数前缀。如果将 DLL 留空
并按下函数前缀的选择按钮，则会显示内置函数前缀的列表。
例如，在 Excel 中复制时产生的剪贴板格式中，若要将 CSV 作为文本处理，
可设置为：
	格式名称: CSV
	DLL:
	函数前缀: text_
这样它就会在菜单和查看器中作为文本处理。

* 筛选
要添加到历史记录中的剪贴板格式，在选项中的“筛选”里设置。

如果选择“将所有格式添加到历史记录”，则除设置为“忽略此格式”的格式外，
所有剪贴板格式都会被添加到历史记录中。
如果选择“将所有格式排除在历史记录之外”，则只有设置为“添加到历史记录”
的剪贴板格式才会被添加到历史记录中。

对于在筛选中设置为“添加到历史记录”的剪贴板格式，还可以设置添加到历史
记录时的大小限制。超过该限制的数据不会被添加到历史记录中。

对于在筛选中设置为“添加到历史记录”的剪贴板格式，如果设置“不保存”，
则 CLCL 退出时不会将其保存到文件中。
例如，可以将 CLCL 设置为文本和图片都添加到历史记录中，但只保存文本。

* 窗口
若要根据所使用的应用程序改变 CLCL 的行为，请在选项中的“窗口”里设置
窗口及其行为。

请指定窗口的标题和类名，其中“*”可以匹配任意字符。
例如，对于记事本：
	标题: * - 记事本
	类名: Notepad
使用该设置后，在记事本处于活动状态时，CLCL 的行为就会发生变化。
标题和类名只需输入其中之一；将其中一项留空与只指定“*”的效果相同。

- 忽略此窗口
	在指定窗口中复制的数据不会被添加到历史记录中。
	如果某个应用程序的数据进入历史记录后无法正常工作，请指定该
	选项，以便忽略来自该应用程序的复制操作。

- 不设置焦点
	指定的窗口被激活后不设置焦点。
	如果在粘贴所选菜单项目时焦点转移到了其他地方，导致粘贴无法
	正常进行，指定该选项可能会解决问题。

- 取消时粘贴
	通常，当您取消一个可取消的工具时，后续的粘贴不会执行；但指定
	该选项后，即使取消也会执行粘贴。
	如果在各窗口的按键设置中将复制键设置为剪切键，指定该选项可以
	防止取消工具时丢失文字。

* 各窗口的按键设置
当您通过热键选择历史记录或模板项目并自动粘贴时，程序会向窗口发送粘贴键。
默认情况下会向所有窗口发送 Ctrl + V，但在某些窗口中粘贴键可能不同。

通过热键调用工具时，CLCL 会执行复制 -> 工具处理 -> 粘贴，因此会向窗口
发送复制键（Ctrl + C）。

各窗口的复制键和粘贴键在选项中的“键”里设置。
请设置要配置的窗口的标题和类名，并设置复制键和粘贴键。

如果未设置复制键和粘贴键，则使用默认的按键设置。

一个窗口可以设置多个按键。设置多个时，将按照列表中从上到下的顺序发送。

* 工具（插件）
若要处理历史记录或模板项目的数据，或者扩展 CLCL 的功能，请在选项中的
“外挂 DLL 插件设置”里进行设置。

选择 DLL 和函数名称后，工具的标题和调用类型会被自动设置。
调用类型中的“动作菜单”可使该工具从选项中的“动作”所设置的菜单中调用。
调用类型中的“查看器菜单”可使该工具从查看器的“工具”菜单中调用。

调用类型中的“发送复制与粘贴”会向活动窗口发送复制操作，对复制到的数据
执行工具处理，并将结果粘贴到活动窗口中。
如果未勾选该选项，则工具会对最新的历史记录项目执行处理，并将结果发送到
剪贴板。在动作菜单中右键点击项目时显示的工具菜单中，工具会对所选项目
执行处理，并将结果发送到剪贴板。
如果在动作设置中未启用“自动粘贴”，则在复制并执行工具后不会进行粘贴。

如果将 DLL 拖放到工具列表窗口中，则会显示可注册的工具列表，您可以从中
选择多个工具并一次性注册。

* 命令行
启动 CLCL 时可以指定命令行，以指定启动后要执行的操作。
如果 CLCL 已在运行，该命令会被发送到正在运行的 CLCL。

[格式]
CLCL.exe [/vwnx]
	/v 显示查看器
	/w 开启监视剪贴板
	/n 关闭监视剪贴板
	/x 退出程序
