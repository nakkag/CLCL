
----[Plugin DLL]----------------------------

ツールプラグインがエクスポートする関数 (tool_template.c を参照)
  get_tool_info_w(hWnd, index, TOOL_GET_INFO *tgi)
    ツールの一覧を返します。index を 0 から順に呼び出し、FALSE を返すまで続けます。
  <func_name>(hWnd, TOOL_EXEC_INFO *tei, TOOL_DATA_INFO *tdi)
    tgi->func_name に設定した名前の関数で、ツールの処理を行います。
    対象のアイテムが無い呼び出し (CALLTYPE_START / CALLTYPE_END /
    CALLTYPE_VIEWER_OPEN / CALLTYPE_VIEWER_CLOSE やクリップボードの選択時など) では
    tdi が NULL になります。
  <func_name>_property(hWnd, TOOL_EXEC_INFO *tei)
    ツールの設定画面を表示します (任意)。

形式プラグインがエクスポートする関数 (format_template.c を参照)
  get_format_header(hWnd, index, FORMAT_GET_INFO *fgi)
    形式の一覧を返します。index を 0 から順に呼び出し、FALSE を返すまで続けます。
  <func_header>initialize, <func_header>get_icon, <func_header>free,
  <func_header>initialize_item, <func_header>copy_data, <func_header>data_to_bytes,
  <func_header>bytes_to_data, <func_header>get_file_info, <func_header>data_to_file,
  <func_header>file_to_data, <func_header>free_data, <func_header>free_item,
  <func_header>get_menu_title, <func_header>get_menu_icon, <func_header>get_menu_bitmap,
  <func_header>get_tooltip_text, <func_header>window_create, <func_header>window_destroy,
  <func_header>window_show_data, <func_header>window_save_data,
  <func_header>window_hide_data, <func_header>show_property
    fgi->func_header に設定した文字列を先頭に付けた名前の関数を GetProcAddress で
    取得します。必要なものだけエクスポートしてください (無い関数は呼ばれません)。

struct_size
  各構造体の先頭にある struct_size には、本体が sizeof(構造体) を設定して渡します。
  本体の構造体がプラグイン側のヘッダより小さい (古い) 場合に備えて、struct_size より
  後ろのメンバにはアクセスしないでください。

メモリの確保と解放
  本体とプラグインの間で受け渡すメモリは LocalAlloc(LMEM_FIXED) で確保し、受け取った
  側が LocalFree で解放します。
  ・<func_header>data_to_bytes と <func_header>get_tooltip_text が返すメモリは本体が
    LocalFree します。
  ・<func_header>get_menu_title で free_title を TRUE にした menu_title は本体が
    LocalFree します。
  ・TOOL_EXEC_INFO の cmd_line は本体が LocalAlloc で確保して渡し、呼び出し後に
    LocalFree します。差し替える場合は元の文字列を LocalFree してから
    LocalAlloc(LMEM_FIXED) で確保した文字列を設定し、元のポインタは保持しないで
    ください。
  ・WM_ITEM_TO_BYTES が返すバイト列はプラグインが LocalFree します。


----[General]----------------------------

WM_GET_VERSION
  wParam - 0
  lParam - 0
  戻り値 - (int)バージョン
  機能:
    CLCLのバージョンを取得します。

WM_GET_WORKPATH
  wParam - 0
  lParam - (TCHAR *)作業ディレクトリのパス (OUT)
  戻り値 - 0
  機能:
    作業ディレクトリのパスを取得します。
    通常は "%LOCALAPPDATA%\CLCL"、ポータブル設定 (clcl_app.ini の portable=1) の
    場合は CLCL.exe があるディレクトリになります。
    lParam には MAX_PATH 文字以上のバッファを指定してください。

WM_GET_CLIPBOARD_WATCH
  wParam - 0
  lParam - 0
  戻り値 - (int)0 - 監視していない、1 - 監視中
  機能:
    クリップボードの監視状態を取得します。

WM_SET_CLIPBOARD_WATCH
  wParam - (int)0 - 解除、1 - 監視
  lParam - 0
  戻り値 - 0
  機能:
    クリップボードの監視を切り替えます。

WM_GET_FORMAT_ICON
  wParam - (int)アイコンのサイズ
  lParam - (TCHAR *)形式名
  戻り値 - (HICON)アイコンのハンドル
  機能:
    形式用アイコンを取得します。
    アイコンのハンドルは利用し終わると破棄してください。

WM_ENABLE_ACCELERATOR
  wParam - (BOOL)TRUE - 有効、FALSE - 無効
  lParam - 0
  戻り値 - 0
  機能:
    アクセラレータの有効・無効を切り替えます。

WM_REGIST_HOTKEY
  wParam - 0
  lParam - 0
  戻り値 - 0
  機能:
    ホットキーを登録します。

WM_UNREGIST_HOTKEY
  wParam - 0
  lParam - 0
  戻り値 - 0
  機能:
    ホットキーを解除します。

WM_HISTORY_CHANGED

  機能:

WM_HISTORY_GET_ROOT
  wParam - 0
  lParam - 0
  戻り値 - (DATA_INFO *)履歴アイテムのルート

    履歴アイテムを取得します。

WM_HISTORY_LOAD

  lParam - 0
  戻り値 - (BOOL)TRUE - 成功、FALSE - 失敗
  機能:
    現在の履歴を破棄して履歴を再読み込みします。

WM_HISTORY_SAVE
  wParam - (int)0 - オプションに従う、1 - 強制的に保存
  lParam - 0
  戻り値 - (BOOL)TRUE - 成功、FALSE - 失敗
  機能:
    履歴を保存します。

WM_REGIST_CHANGED

  lParam - 0
  戻り値 - 0
  機能:
    登録アイテムの変更を通知します。
    これを送るとビューアで表示の更新をします。

WM_REGIST_GET_ROOT
  wParam - 0
  lParam - 0
  戻り値 - (DATA_INFO *)登録アイテムのルート
  機能:
    登録アイテムを取得します。

WM_REGIST_LOAD
  wParam - 0
  lParam - 0
  戻り値 - (BOOL)TRUE - 成功、FALSE - 失敗
  機能:
    現在の登録アイテムを破棄して登録アイテムを読み込みします。

WM_REGIST_SAVE
  wParam - 0
  lParam - 0
  戻り値 - (BOOL)TRUE - 成功、FALSE - 失敗
  機能:
    登録アイテムを保存します。


----[Item]----------------------------

WM_ITEM_TO_CLIPBOARD
  wParam - 0
  lParam - (DATA_INFO *)アイテム
  戻り値 - (BOOL)TRUE - 成功、FALSE - 失敗
  機能:
    アイテムをクリップボードに送ります。

WM_ITEM_CREATE
  wParam - (int)作成する種類 (TYPE_DATA or TYPE_ITEM or TYPE_FOLDER)
  lParam - wParam によって変化
               TYPE_DATA - (TCHAR *)形式名
               TYPE_ITEM - (TCHAR *)タイトル
               TYPE_FOLDER - (TCHAR *)タイトル
  戻り値 - (DATA_INFO *)作成したアイテム
  機能:
    アイテムを作成します。

WM_ITEM_COPY
  wParam - 0
  lParam - (DATA_INFO *)コピー元アイテム
  戻り値 - (DATA_INFO *)コピーしたアイテム
  機能:
    アイテムのコピーを作成します。

WM_ITEM_FREE
  wParam - 0
  lParam - (DATA_INFO *)解放するアイテム
  戻り値 - 0
  機能:
    アイテムを解放します。
    nextとchildに設定されたアイテムも解放するためリスト中の1アイテムのみを解放
    する場合は、リストからアイテムを削除してからこのメッセージを呼んでください。

WM_ITEM_FREE_DATA
  wParam - (TCHAR *)形式名
  lParam - (HANDLE)解放するデータ
  戻り値 - 0
  機能:
    データを解放します。
    アイテムに含まれる di->data を解放する時に呼びます。

WM_ITEM_CHECK
  wParam - 0
  lParam - (DATA_INFO *)チェックするアイテム
  戻り値 - (int)-1 - 存在しない、0 - 履歴に存在する、1 - 登録アイテムに存在する
  機能:
    アイテムの存在をチェックします。

WM_ITEM_TO_BYTES
  wParam - (DWORD *)変換後のサイズ (OUT)
  lParam - (DATA_INFO *)変換するアイテム
  戻り値 - (BYTE *)変換後のバイト列
  機能:
    アイテムをバイト列に変換します。
    戻り値のバイト列は LocalAlloc で確保されているため、利用し終わったら
    LocalFree で解放してください。

WM_ITEM_FROM_BYTES
  wParam - (BYTE *)変換するバイト列
  lParam - (DATA_INFO *)設定するアイテム
  戻り値 - 0
  機能:
    バイト列からデータを作成しアイテムに設定します。

WM_ITEM_TO_FILE
  wParam - (TCHAR *)ファイル名
  lParam - (DATA_INFO *)保存するアイテム
  戻り値 - (BOOL)TRUE - 成功、FALSE - 失敗
  機能:
    アイテムをファイルに保存します。

WM_ITEM_FROM_FILE
  wParam - (TCHAR *)ファイル名
  lParam - (DATA_INFO *)設定するアイテム
  戻り値 - (BOOL)TRUE - 成功、FALSE - 失敗
  機能:
    ファイルからデータを作成してアイテムに設定します。

WM_ITEM_GET_PARENT
  wParam - 0
  lParam - (DATA_INFO *)親アイテムを取得するアイテム
  戻り値 - (DATA_INFO *)親アイテム、見つからない場合は NULL を返す。
  機能:
    アイテムの親アイテムを取得します。

WM_ITEM_GET_FORMAT_TO_ITEM
  wParam - (TCHAR *)形式名
  lParam - (DATA_INFO *)アイテム情報
  戻り値 - (DATA_INFO *)TYPE_DATAのアイテム
  機能:
    指定の形式名をアイテムから検索する。

WM_ITEM_GET_PRIORITY_HIGHEST
  wParam - 0
  lParam - (DATA_INFO *)TYPE_ITEMのアイテム
  戻り値 - (DATA_INFO *)TYPE_DATAのアイテム
  機能:
    優先順位の高い形式のアイテムを取得します。

WM_ITEM_GET_TITLE
  wParam - (TCHAR *)タイトル (OUT)
  lParam - (DATA_INFO *)タイトルを取得するアイテム
  戻り値 - 0
  機能:
    アイテムのタイトルを取得します。
    タイトルの長さに上限は無いため、wParam には十分な長さ (BUF_SIZE * 2 文字以上を
    推奨) のバッファを指定してください。

WM_ITEM_GET_OPEN_INFO
  wParam - (OPENFILENAME *)ファイル情報 (OUT)
  lParam - (TCHAR *)形式名
  戻り値 - (int)-1 - コモンダイアログを表示しない、0 - 未設定、1 - 設定済み
  機能:
    形式毎のファイルを開く情報を取得します。

WM_ITEM_GET_SAVE_INFO
  wParam - (OPENFILENAME *)ファイル情報 (OUT)
  lParam - (DATA_INFO *)保存情報を取得するアイテム
  戻り値 - (int)-1 - コモンダイアログを表示しない、0 - 未設定、1 - 設定済み
  機能:
    アイテムのファイル保存情報を取得します。
